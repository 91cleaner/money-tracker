# MONEY TRACKER — 인수·매각용 한 장 소개서 (초안)

> 작성 기준: 2026-10-29. **제품 소개용 초안이지 실사(due diligence) 완료 보고서가 아닙니다.** 기능·데이터 범위·접근 통제는 인수 전에 다시 검증해야 합니다.

## 한 줄 소개
**세계지도를 탐색하며 공개된 의회 법안, 미국 의원의 주식 거래 *신고*, 기업·산업, 거시경제 및 역사적 사건의 연결 맥락을 추적하는 데이터 관제실.** 이용자가 질문하고 후보 경로를 선택한 다음 지도를 따라 원문으로 이동하는 조사형 경험을 지향합니다.

## 사용자가 얻는 가치
- **탐색 경험:** 한 화면 세계지도에서 국가·기업·의원·법안을 따라가며 공개 기록의 시간순 맥락을 살펴봅니다. 화면의 경로선은 탐색을 돕는 시각화이며 **인과관계의 증거가 아닙니다**.
- **원문 중심 검증:** 신고일과 거래일, 사건 발생일과 데이터 수집일을 구분하고, 가능한 경우 원문 링크로 이동합니다.
- **재방문 동기:** 관심 기업·산업·의원·정책의 새로운 공개 기록을 다시 확인하는 조사 워크플로를 지향합니다. 현재 화면별 구현·배포 수준은 서로 다를 수 있습니다.

## 현재 데이터 파이프라인과 출처
| 분야 | 저장소의 수집·저장 경로 | 반드시 표시할 한계 |
|---|---|---|
| 미국 의회 법안 | Congress.gov 기반 `data/us/bills.json`; 정기 수집 워크플로 `us.yml` | API 접근·수집 성공 여부에 따라 갱신 지연 가능 |
| 미국 하원 의원 주식 신고 | House Clerk 공개 PTR에서 파싱한 `data/us/trades.json`; `us.yml` 및 관련 검증 | **실제 체결 확인 데이터가 아니라 신고 자료**. 신고 지연·금액 구간·파싱 오차 가능. 상원 포괄 수집은 미확인 |
| 미국 거시경제 | FRED 기반 `data/us-macro.json`; `us-data.yml` | 성공적으로 수집한 경우에만 파일 존재·갱신. 시차·개정 가능 |
| 한국 공공계약·의회 | 공공데이터·국회 관련 수집기와 `data/index.json`, `data/city/`, `data/national/` | 기관별 접근권한·누락·기준일을 따로 표시해야 함 |
| 역사·정책 사건 | `data/us-events.json` 등 출처 링크가 있는 정리 자료 | 큐레이션 자료이며 사건과 주가의 인과관계를 주장하지 않음 |

**운영 방식:** 일부 수집기는 매시 또는 매일 자동 실행되도록 설정돼 있습니다. **스케줄 존재 ≠ 매일 수집 성공**입니다. 최신성·건수·정확성은 각 실행 기록과 원본 대조 결과로 검증해야 합니다.

## 주요 고객과 활용
경제·정책 전문 미디어, 리서치 조직, 공공 데이터 분석 서비스, 시민단체 및 교육·역사 콘텐츠 제작자가 공개 기록을 탐색하고 출처를 확인하는 도구로 활용할 수 있습니다. **매수·매도 추천, 수익률 보장, 내부정보 판정 서비스는 아닙니다.**

## 확장 로드맵 (현재 구현·검증 완료로 표현하지 않음)
1. **미국 연방 계약 의무액:** USAspending.gov의 계약·수혜 기업 기록을 기업·지역·시점에 연결.
2. **미국 로비:** 미 상원 LDA 공개 신고에서 로비 주체·고객·이슈·기간을 연결.
3. **미국 정치 후원금:** FEC 공개 자료에서 후원·수령·기간을 연결.
4. **미국·한국·일본·대만:** 공개 출처별 식별자 매칭과 다국어 시간축을 단계적으로 확대.

## 매각 전 반드시 해결할 사항
- **보안/배포 차단 요건:** 2026-10-29 조회 기준 GitHub 저장소는 `public`입니다. 기존 검사에서 Pages 제한 경로의 HTTP 200 응답이 보고됐고, `legacy` 배포 설정 위험도 남아 있습니다. [보안 대응 PR #214](https://github.com/91cleaner/money-tracker/pull/214), [노출 검사 PR #213](https://github.com/91cleaner/money-tracker/pull/213), [배포 이중화 이슈 #116](https://github.com/91cleaner/money-tracker/issues/116) 해결과 **실사이트 재검증** 전에는 비공개·안전 배포를 주장하지 않습니다.
- **핵심 UX:** 종목 검색이 후보 선택을 건너뛰는 [이슈 #174](https://github.com/91cleaner/money-tracker/issues/174)를 해결하고, 모바일에서 질문 → 후보 선택 → 지도 추적을 E2E 검증해야 합니다.
- **데이터 품질:** 하원 신고 원문 대조, 기간·날짜 표기, 결측·갱신 실패, 회사·의원·법안 식별자 일치율을 수치로 검증해야 합니다.
- **서비스 상태:** **AI 분석 미연결 / 실시간 체결 데이터 미연결.** 정적 검색·미리 계산된 문장은 생성형 AI 또는 실시간 매매 데이터로 판매하지 않습니다. 실제 운영 배포 및 유료 구독·매출은 이 문서로 입증하지 않습니다.

**실사 패키지 권장:** 데이터 출처·라이선스·재배포 권한, 수집 성공률/갱신 지연, 테스트·배포 기록, 접근 통제, 운영비, 사용자 지표, 코드·데이터 소유권을 별도 증빙으로 준비합니다.
