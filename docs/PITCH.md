# MONEY TRACKER — 인수·제휴 검토용 1페이지 소개서

> 2026-10-31 기준 제품 설명 초안. **구현된 기능, 수집 가능한 공개 기록, 앞으로의 계획을 구분**합니다. 실제 서비스·라이선스·보안 실사는 별도입니다.

## 한 줄 소개
**세계지도 위에서 국가·법안·의원 공개 거래 신고·기업·경제 지표를 출처와 함께 탐색하는 공개자료 기반 리서치 관제실.** 방문자는 질문의 후보를 고르고 지도에서 관련 국가와 기록을 따라갑니다. 지도 경로는 탐색 연출이며, 사건 간 인과관계나 내부정보를 의미하지 않습니다.

## 무엇을 제공하나
- **지도형 탐색:** 평면 세계지도 관제실(`world-intelligence/index.html`)과 미국 경제·역사·하원 공개 신고 연구 화면(`world-intelligence/us-signals.html`). 모바일·국가별 화면은 지속 개선 중입니다.
- **원문 중심 연결:** Congress.gov 법안 요약(`data/us/bills.json`), 미국 하원 Clerk의 PTR 공개 신고에서 추출한 거래 *신고* 기록(`data/us/trades.json`), 출처 링크가 있는 역사 사건(`data/us-events.json`)을 탐색합니다. 거래 금액은 범위이며, 신고 내용이 실제 체결·수익률·위법행위를 입증하지 않습니다.
- **검증 가능성:** 하원 신고 원문 PDF 및 필드 대조(`data/us/ptr-crosschecks.json`)와 자료의 사건일·거래일·신고일·수집일을 구분하는 원칙을 둡니다. 연결이 확인되지 않은 관계는 추정 사실로 표시하지 않습니다.

## 데이터 수집의 현재 상태
| 자료 | 출처·자동화 | 확인해야 할 제한 |
|---|---|---|
| 미국 법안 | Congress.gov 공개 API / 저장소의 수집·동기화 작업 | API 키·실행 성공 여부 확인 필요 |
| 미국 하원 거래 신고 | House Clerk 공개 PDF / 추출·대조 작업 | 신고 지연·추출 실패·원문 링크 검증 필요; 상원 전체 포괄 아님 |
| 미국 거시경제 | FRED / 예약 수집 워크플로 | 성공 실행 후에만 파일 생성; 갱신일과 최신성 별도 확인 |
| 한국 지방계약 | 공개 계약 자료 / 기존 수집 워크플로 | API 오류·자료 이용조건·개인정보 처리 검증 필요 |

**자동화 코드가 있다는 사실만으로 매일 모든 자료가 성공적으로 갱신된다고 주장하지 않습니다.** 화면과 데이터의 마지막 성공 수집 시각, 실패·미확인 상태는 운영 검증 대상입니다.

## 누가 쓰나
정책·기업·산업 흐름을 조사하는 기자, 연구자, 분석가, 교육·시사 콘텐츠 제작자. 정보 탐색과 원문 검증을 돕는 도구이며 매수·매도 추천 서비스가 아닙니다.

## 다음 데이터 확장 후보 — 아직 구현·검증 완료로 표시하지 않음
- 미국 **연방 계약금·조달**: USAspending.gov 등 공식 공개 자료와 수주 기업·지역 연결
- 미국 **로비**: 공식 로비 공시와 법안·조직·시점 연결
- 미국 **정치 후원금**: FEC 공식 공시와 후보자·위원회·기업 관련성 검토
- 한국·일본·대만의 공개 법안·기업·국가 이벤트를 동일한 출처 검증 방식으로 확장

## 인수 전 필수 확인
1. **데이터 권리:** 주가·제3자 데이터의 상업 이용·재배포·양도 권한은 아직 확정하지 않음.
2. **접근 통제:** 현재 GitHub 저장소 및 GitHub Pages는 공개 접근이 가능함. `noindex`는 인증이 아님. 관리자 Worker의 실제 배포·OAuth 인증은 별도 확인 필요.
3. **기술 검증:** 수집 성공률·원문 일치율·모바일 UX·자동 테스트·실서비스 배포를 실사하고, 실패 시 '0건'과 '연결 실패'를 구별해야 함.
4. **연결 상태:** **생성형 AI 분석 미연결 / 실시간 거래 체결 데이터 미연결.** 현재 거래 정보는 공개 신고 자료 중심.
