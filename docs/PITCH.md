# MONEY TRACKER — 인수 검토용 1장 소개서 (초안)

> **한 줄 설명**: 세계지도 위에서 국가별 정책·법안·공개 금융신고·기업·시장 사건을 원문 증거와 함께 탐색하는 **공공데이터 기반 리서치 관제실**.

## 무엇을 해결하나

정책 발표, 법안 진행, 의원 재산거래 신고, 기업 및 시장 정보는 기관과 국가별로 흩어져 있습니다. MONEY TRACKER는 사용자가 **질문 → 국가·인물·사건 선택 → 지도 이동 → 공식 원문 확인**이라는 한 화면의 탐색 흐름으로 자료를 비교하도록 설계되었습니다. 지도 이동선과 시간적 인접성은 **인과관계나 투자 신호를 뜻하지 않습니다**.

## 제품과 데이터 파이프라인

- **미국**: [Congress.gov](https://www.congress.gov/) 법안·의원 자료, [미국 하원 Clerk](https://disclosures-clerk.house.gov/)의 공개 PTR 신고 원문, [Federal Register](https://www.federalregister.gov/) 행정 공고, [SEC](https://www.sec.gov/) 공개자료, [FRED](https://fred.stlouisfed.org/) 거시경제 시계열(키·수집 성공 여부에 따라 제공).
- **일본·대만·한국**: 일본 의회·대만 입법원·한국 공공기관의 공개 자료를 대상으로 국가별 수집과 탐색을 확장 중. **수집 실패·공백·미연결을 정상 수집으로 표시하지 않습니다.**
- **자동화**: GitHub Actions로 미국 거시·하원 신고 색인 수집을 매일 예약하고, 다른 수집기는 각 워크플로 일정에 따릅니다. 일정이 존재해도 **매일 모든 데이터가 성공적으로 갱신된다는 뜻은 아닙니다**. 원문 링크, 기준 날짜, 수집 상태, 검증 범위를 구분합니다.
- **확인된 예시**: `data/search/collection-status.json`의 2026-11-01 19:10 UTC 스냅샷에는 미국 Federal Register 105건, 미국 SEC 74건, 일본 의회 46건, 대만 입법원 0건·수집 오류가 기록되어 있습니다. **전체 보유량·당일 신규 수집량·원문 정확성 인증 수치가 아닙니다.**

## 누가 쓰나

정책·산업 리서처, 경제·정치 기자, 대학·연구기관, 기업의 규제·대외협력 담당자, 공공데이터를 원문까지 추적하려는 이용자. 투자 판단을 대신하거나 불법행위·내부정보 이용을 추정하는 서비스가 아닙니다.

## 매수자에게 제공할 잠재 가치

단일 지도 관제실 UX, 다국가 데이터 수집·정규화 작업, 공식 출처 연결, 수집·배포 검증 체계, 향후 사건·기관·기업 관계 그래프의 확장 가능성. **공개 원자료 자체를 독점 자산으로 주장하지 않으며**, 인수 실사에서는 코드 권리·데이터 재배포 라이선스·접근통제·비용·데이터 신선도를 별도 확인해야 합니다.

## 다음 확장과 현재 제약

**현재 연방계약 시범 데이터**: `data/us/federal-awards.json`(2026-11-02 스냅샷)에 [USAspending.gov](https://www.usaspending.gov/)의 계약 의무액(`obligations`) 집계가 존재합니다. 파일 메타데이터 기준 **기업 후보 250개 확인, 70개 매칭**, `DE:partial`·`GD:partial` 오류가 기록돼 있습니다. 이는 전체 미국 연방계약의 완전한 수집이나 기업별 실제 현금 지급액이 아니며, 수혜자 ID·명칭 일치와 일부 자회사 범위에 제한됩니다.

**현재 로비·정치후원금 시범 데이터**: `data/us/lobbying.json`(2026-11-02 스냅샷)은 [미국 LDA 공개 공시](https://lda.gov/api/)의 **2025~2026년 기업 후보 150개 조회·116개 매칭·파일상 오류 0건**을 기록합니다. 기업명으로 시작하는 의뢰인만 집계하므로 전수조사가 아니며, `total_usd`는 신고된 외부 로비 수입(`income`)과 자체 로비 비용(`expenses`)의 조건부 합계이지 기업이 직접 지출한 확정액이 아닙니다. `by_quarter`에는 `1A`·`1T`·`RR` 등 분기 외 신고 유형도 들어가므로 모든 항목을 분기 지출로 해석할 수 없습니다. 수정·중복 신고와 법안 번호의 회기 식별은 별도 원문 대조가 필요합니다.

`data/us/pac-contributions.json`(2026-10-30 스냅샷)에는 [FEC 공개 PAC](https://www.fec.gov/data/) 집계가 이미 있으나 `rate_limited: true`가 기록되어 **수집 완전성은 미검증**입니다. 기업 연계 PAC는 회사의 직접 정치 기부금과 다르며 개별 후보별 관계까지 검증 연결됐다고 주장하지 않습니다.

**연결 로드맵**: 위 연방계약·LDA·FEC **기존 시범 파일**을 법안→의원→기업→산업 타임라인에 공식 원문·기간·관계 유형과 함께 검증 연결하고, 중복·부분 수집·수정 신고·출처별 라이선스 검사를 보강합니다. **데이터 파일 존재와 관제실 연결·운영 검증 완료는 별개**입니다.

**현재 상태 (2026-11-03)**: 제품은 개발·검증 단계. 저장소 및 GitHub Pages는 **공개(public)** 상태로, 기밀/회원전용 데이터 저장소로 간주할 수 없습니다. 미국 하원 PTR은 **사후 신고**이며 실시간 체결 데이터가 아닙니다. 생성형 AI 검색·분석 **미연결**. 법안→의원→기업의 전면적 검증 연결, 모바일 완성도, 배포·보안 게이트의 통합 검증은 **완료로 주장하지 않습니다**.
