# MONEY TRACKER — 매각 검토용 한 장 소개서 (초안)

> **한 문장:** 국가 정책·법안·공개 금융공시·기업 정보를 하나의 세계지도에서 따라가며 **사실과 시점을 대조하는 조사형 데이터 관제실**.

**제품 경험**  
사용자가 국가·기업·질문을 선택하면 지도 위에서 관련 지역과 기록을 따라가고, 사건의 날짜·원문·연결 근거를 확인한다. 한 화면의 지도, 탐색 경로, 브리핑과 기간 필터를 결합해 복잡한 자료를 게임처럼 탐색하도록 설계했다. **지도 선은 탐색 경로이지 인과관계나 내부정보의 증거가 아니다.**

**현재 확인 가능한 자료와 자동화**  
- **미국 법안:** Congress.gov 기반 법안 요약·진행 상태. API 키와 수집 성공 여부에 따라 범위·최신성이 달라진다.
- **미국 하원 의원 공시:** House Clerk의 금융공시 목록 및 공개 PTR 거래 신고 자료와 원문 PDF 링크. 신고 금액은 구간이고, 거래일과 신고일은 다르다. 추출·교차검증 상태를 구분해야 한다. **상원 전체 거래를 포괄한다고 주장하지 않는다.**
- **경제·역사:** FRED 거시경제 관측치 수집 작업과 출처를 단 역사적 사건 데이터. 관측일·수집일·사건일을 분리한다.
- **기타 연결 자료:** 공개 계약·기업·정책 자료를 연계하는 데이터 수집·검색 작업을 확장 중이다. 각 자료의 실재 여부, 건수, 갱신 성공과 원문 링크는 데이터셋별로 확인해야 한다.

GitHub Actions에 일일·수동·변경 시 실행되는 수집 및 검증 작업이 있다. **워크플로 성공은 신규 자료 확보, 완전한 국가별 커버리지 또는 최신 데이터의 보증이 아니다.** 자동 수집이 실패하거나 자료가 없으면 '미수집/오류/검증 대기'로 표시해야 한다.

**누가 사용하는가**  
정책·산업 분석가, 언론·리서치 조직, 기업 전략팀, 공개 데이터 기반 조사를 수행하는 연구자, 그리고 정치·경제 사건을 맥락과 함께 탐색하려는 일반 이용자. 사용 목적은 **출처 추적과 사실 검증**이며 투자 추천이나 자동매매가 아니다.

**확장 로드맵**  
미국 연방 계약 **집행액·수주처**(USAspending 등), 로비 공시(LDA), 정치 후원금(FEC)을 법안→의원→기업→기관의 근거 중심 관계로 연결한다. 이후 한국·일본·대만의 검증 가능한 공식 자료를 국가별 법적 이용 조건에 맞춰 확장한다. 연결은 동일 이름이나 날짜만으로 확정하지 않고, 출처·식별자·신뢰도·검토 상태를 보존한다.

**인수자 관점의 가치**  
원문에서 탐색 경로까지 이어지는 사용자 경험, 정규화된 데이터 모델, 수집·품질 검증 자동화, 출처 및 수정 이력 관리가 결합된 **확장 가능한 조사 제품의 기반**. 원본 정부 공공자료 자체를 독점 자산으로 주장하지 않는다. 차별화 가능한 자산은 검증된 엔터티 매핑, 재현 가능한 정합성 검사, 사용성, 운영 체계와 권리가 확보된 자체 코드다.

**매각 실사 전 반드시 해결할 사항**  
1. **접근통제:** 2026-10-29 조회 기준 저장소는 `public`. GitHub Pages에 올린 파일은 비공개로 간주할 수 없다. 서버 측 인증, 민감자료 분리, 기존 노출 파일 감사 및 실제 익명 접근 차단 검증이 선행되어야 한다.
2. **정확성:** 카드별 공식 원문 링크, 주가·사건 기간의 기준일, 데이터 오류/누락 상태를 정리하고 모바일·자동 테스트를 통과시켜야 한다.
3. **권리·운영:** 제3자 데이터 이용약관·재배포 권한, 외부 지도 타일 라이선스, 코드·데이터 소유권, 수집 실패 로그와 배포 증거를 정리해야 한다.

**현재 한계:** AI 분석 엔진 **미연결** · 실시간 체결 데이터 **미연결**. 하원 PTR은 **사후 공개 신고**이며 체결 확인 자료가 아니다. 투자 수익률·내부자 거래·정책의 주가 영향은 이 자료만으로 단정할 수 없다.

*내부 매각 검토용 초안. 기능 완성·수익·고객 수·기업가치·운영 보안을 보증하는 영업자료가 아니다. 각 항목은 실사 시 재검증 필요.*
