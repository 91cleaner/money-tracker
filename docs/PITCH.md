# MONEY TRACKER — 매각 검토용 1장 소개서 (초안)

**한 줄 설명:** 공개된 법안·정책·의원 재산거래 신고·기업 정보를 **하나의 세계지도 관제실**에서 출처를 따라 탐색하는 데이터 리서치 플랫폼.

## 제품 경험

사용자는 국가 또는 주제를 선택하고 질문을 입력한 뒤, 후보 자료를 선택해 **질문 → 선택 → 지도 추적** 흐름으로 사건의 지리적·시간적 맥락을 탐색합니다. 목표는 복잡한 정책과 금융 공시를 쉽게 읽는 게임형 관제 경험입니다. 지도 위 연결선은 **탐색 경로**이며 거래 인과관계나 비공개 정보의 증거가 아닙니다. 현재 모바일 및 실제 배포 UX는 추가 검증이 필요합니다.

## 데이터 자산과 자동 수집

| 데이터 범주 | 소스/경로 | 현재 입증 가능한 수준 |
| --- | --- | --- |
| 미국 연방 규제·정책 | Federal Register 공개 기록, `data/search/collection-status.json` | 최신 확인 스냅샷에 108건 집계; 원문·날짜별 검증 별도 |
| 미국 상장기업 공시 | SEC 공개 기록, 동일 수집 상태 파일 | 76건 집계; SEC 전체를 포괄한다는 의미 아님 |
| 일본 국회 | 일본 국회 공개 기록, 동일 상태 파일 | 46건 집계; 전체 법안·회의를 포괄하지 않음 |
| 대만 입법원 | 대만 입법원 수집기 | **0건, 8개 fetch 실패** — 수집 실패/자료 미확보, 입법 활동 0건이 아님 |
| 미국 의회 법안 | Congress.gov, `data/us/bills.json` | 공개 법안 요약·출처 탐색; API 수집에는 키 필요 |
| 미국 하원 의원 거래 신고 | House Clerk PTR 원문 PDF 및 `data/us/trades.json` | 신고된 거래의 연구용 파싱 자료; **실제 체결의 독립 검증이나 실시간 피드 아님** |

수집·색인 갱신 자동화가 저장소에 존재하지만, **각 수집기의 매일 성공이나 데이터 완전성을 보장하지 않습니다**. 상태는 수집별 오류와 마지막 관측 시각으로 표시해야 합니다. 위 108/76/46/0은 2026-11-04 04:21 KST 생성된 상태 스냅샷 기준이며, 현재 재수집 건수가 아닙니다.

## 누가 쓰는가

정책·규제 리서치 팀, 금융 데이터 분석가, 언론사 데이터 저널리스트, 기업 전략·공급망 담당자, 대학·연구기관이 **원문에 근거한 관계 탐색**과 사건 타임라인에 활용할 수 있습니다. 투자 추천이나 내부자거래 판정 서비스가 아닙니다.

## 매수자가 인수할 수 있는 것과 확인할 것

- **자산 후보:** 지도 기반 관제 UI, 국가별 검색·탐색 구조, 공개 자료 수집/색인 코드, 출처 링크와 데이터 스키마, 자동화 워크플로, 테스트 체계.
- **실사 필수:** 원문 재사용 라이선스·출처별 이용 조건, 수집 성공률과 신선도, 코드·데이터 소유권, 개인정보 및 공개 범위, 보안·모바일 품질, 운영비, 관리자 접근 제어.
- **현 상태:** GitHub 저장소와 GitHub Pages는 **PUBLIC**. 생성형 AI 검색/분석 **미연결**, 실시간 의원 **실제 체결** 데이터 **미연결**. 법안→의원→기업의 검증된 인과관계 자동 추론은 미구현. 관련 공개 검증·배포 보호 PR들은 승인·병합·실배포 확인이 필요합니다.
