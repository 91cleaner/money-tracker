# P1 제2 검토: SPCX 종목코드 재사용으로 인한 연초 수익률 오표시

- **확인 시점:** 2026-10-30 20:57 KST
- **문제 추적:** [#371](https://github.com/91cleaner/money-tracker/issues/371)
- **담당 분리:** GPT는 문서/코드 검토만. `data/`·수집기 수정은 실장, `world-intelligence/` 화면은 클로드 담당 ([AI-ROLES](AI-ROLES.md)).
- **판정:** 사용자에게 표시되는 **SPCX 연초 대비 +566.65%**는 현재 SpaceX 주식의 2026년 연초 대비 수익률로 성립할 수 없음. 과거 다른 증권이 같은 티커를 사용했으므로 티커만으로 과거 가격을 연결하는 데이터 오염 가능성이 높음. 원시 수집기 내부의 실제 원인은 미확인.

## 코드와 데이터로 재현한 사실

1. `data/us/prices/summary.json`: `date = "2026-10-28"`, `t.SPCX.c = 145.23`, `t.SPCX.ytd = 566.65`, `t.SPCX.from = "2026-09-29"`. 화면의 최근 스파크라인은 9월 29일 이후지만 **연초 대비** 값은 별도로 계산되어 함께 저장됨.
2. `world-intelligence/index.html`의 `mt-price-js`: `const x=P.t&&P.t[tk]` 후 `연초 대비 ` + `f(x.ytd)`를 조건 없이 표시함. 종목코드의 상장일·발행사 변경 여부를 확인하지 않음.
3. `145.23/(1+566.65/100) ≈ 21.79`달러가 +566.65%의 역산 기준가임. SpaceX의 2026년 6월 IPO 공모가 135달러와 구별해야 함. 역산만으로 원시 가격 파일의 어느 날짜가 사용되었는지는 확정할 수 없음.
4. `world-intelligence/ticker-trades.json`은 2026-06-12 이후 SPCX 의원 거래와 당시 주가를 연결하고 있음. **연초 수익률 오표시가 거래 원문 자체의 오류를 증명하지는 않음**. 다만 동일한 티커 재사용 문제가 거래-주가 매칭에도 전파되지 않았는지 확인해야 함.

## 발행사/ETF 공식 자료

- [SpaceX 공식 IPO 발표 (2026-06-11)](https://ir.spacex.com/updates/releases-details/2026/Space-Exploration-Technologies-Corp--Announces-Pricing-of-Initial-Public-Offering/default.aspx): SpaceX 보통주가 2026-06-12부터 Nasdaq에서 **SPCX**로 거래될 예정이며 IPO 공모가는 135달러라고 명시.
- [기존 SPCX ETF의 운용사 공식 안내](https://spcketf.com/): SPAC and New Issue ETF는 2026-04-07 개장 시 티커를 **SPCX → SPCK**로 변경했다고 명시.

즉, **SPCX는 과거 ETF와 현재 SpaceX가 서로 다른 시점에 사용한 동일 문자열**. 티커 문자열은 영구적인 증권 식별자가 아님.

## 데이터 담당 수정 수락 기준

- [ ] 종목코드만으로 가격 이력을 합치지 않고, **발행사/증권 식별자와 티커 유효 기간**을 함께 검증한다. `SPCX` ETF(2026-04-07 이전)와 SpaceX(2026-06-12 이후)를 분리한다.
- [ ] SpaceX의 2026년 1월 시장가격은 없으므로, `SPCX`의 `ytd`는 **`null`/미산출** 처리한다. 임의로 0%를 쓰지 않는다.
- [ ] 상장 후 수익률을 제공하려면 시작일과 가격 정의(IPO 공모가/첫 거래일 종가)를 별도로 명시한다. 이를 '연초 대비'라고 표기하지 않는다.
- [ ] 신규 상장·티커 변경·티커 재사용·상장 폐지 사례를 포함한 회귀 테스트를 추가한다. 해당 날짜 범위 밖의 과거 가격이 차트·수익률·거래가격 매칭에 섞이지 않아야 한다.
- [ ] 가격 원천 일별 기록을 검증해 `ytd=566.65`의 계산 기준일/원천 증권을 식별하고, 다른 티커 재사용 사례도 스캔한다.

## UI 담당 수정 수락 기준

- [ ] `ytd=null` 또는 미산출일 때 **'연초 대비: 산출 불가 (2026-06-12 상장)'**를 표시한다. 0%, +566.65%, '자료 없음=0%'를 표시하지 않는다.
- [ ] 데이터 요청 실패·정상 데이터 0건·미산출 지표를 각각 구별한다. 모바일 가로 844×390 및 세로 375×667에서 날짜와 안내를 확인한다.
- [ ] 가격 출처/기준일과 의원 PTR 신고일을 별도 표기하고, 거래 전후 가격 비교를 인과관계나 투자 신호로 표현하지 않는다.
