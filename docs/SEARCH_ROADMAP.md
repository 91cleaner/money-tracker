# MONEY TRACKER — 범용 검색·관제실 개발 로드맵
기준일: 2026-10-27. 아래 기간은 전담 개발자가 실제로 집중 작업하고 필요한 API·배포 권한을 확보했다는 전제의 대략적 개발 노력 추정치이며 납품 확약이 아니다.

## 본질
질문 → 근거 검색 → 사실 검증 → 역사·국가·법안·의원·기업·시장 관계 연결 → 상승·하락 양쪽 시나리오 → 사용자의 결정 → 지도 현장 추적. 사실과 추론, 과거 기록과 현재 데이터, 관심 분야와 실제 주가 원인을 분리한다. 고등학생도 이해할 문장으로 설명한다.

## 현재 상태
- 중립 관제실: 아무 종목도 기본 선택하지 않는다. mission=nvda 링크는 의도적으로 NVIDIA 경로를 열고 초기화 버튼으로 해제한다.
- 준비된 규칙형 자료: NVIDIA, 미국 반도체법, 관세, 금리, 역사, 미 하원 금융공시 출처 및 지도 경로. 이는 생성형 AI가 아니다.
- 제한적 임의 검색: assets/mt-open-research.js에서 사용자가 별도 버튼을 누르면 Wikimedia의 백과 검색으로 관련 참고 문서를 찾는다. 질의가 Wikimedia로 전송되므로 클릭 전 고지한다. 당일 뉴스·시세·실시간 사건 원인 분석은 불가능하다.
- 이미 진행 중인 공개 미국 의원/법안 데이터 시험실: intel-lab.html 및 data/us 관련 기록. 개별 거래 자동 검증과 통합 추적은 별도 완성 필요.
- 자동 단위 검사는 코드로 작성됐으나 GitHub Actions·GitHub Pages 실제 배포 성공과 Chromium 화면 결과는 별도 검증해야 한다.
- 미국 전용 접근 제한은 현재 적용되지 않았다. 비공개 GitHub 저장소라도 공개 Pages 주소의 HTML/JS는 익명 접근 가능하다.

## 1단계: 자유 질문에 실제로 조사하는 MVP (집중 개발 약 1~2주)
1. 보안된 서버 측 AI/검색 오케스트레이터: 프런트엔드 공개 JS에 AI·금융 API 키를 절대 보관하지 않는다.
2. 운영자 전용 인증과 접근 제한. 프런트엔드 PIN 창은 보안 수단이 아니다. 공개 Pages 미국 파일 노출도 차단한다.
3. 질문 구조화: 기업·인물·국가·법안 식별, 요청 날짜, 실제 원인/전망/연결 관계 구분.
4. 검색·데이터: 미국 의회 공식 기록, SEC EDGAR, 회사 IR, 연준, 공식 역사 자료, 합법적 최신 뉴스·주가 제공자를 검색하는 파이프라인 구축.
5. 증거·출처·기준시각별 요약, 원인 가설, 반대 증거, 다음 공식 발표 및 사용자 선택지 생성.
6. API 실패나 미연결 시 그 사실을 밝히고 억지로 아무 기업/지도로 이동시키지 않는다.

## 2단계: 법안·의원·기업 관계와 시장 인사이트 (추가 약 3~6주)
- 법안 고유번호 → 공식 발의 의원·위원회·표결 → 정부 지원 사업 → 수혜 기업 → 공개 주식 티커. 실제 식별자가 있는 관계만 사실로 표시한다.
- 의원 거래 원문 → 거래일·신고일·금액 구간·거래자·정정 신고를 저장. 시간적 연관이 부당이득의 증거라는 주장을 하지 않는다.
- 주가와 뉴스는 라이선스가 확보된 데이터 제공자로부터 시점·지연 여부를 구분해 수집.
- 세계지도 이동은 대륙→국가→도시/건물로 단계화하며 사용자는 언제든 건너뛰거나 제어한다.
- 실제 장소·의원 사진은 출처 및 이용 허락 조건 확인.
- 반도체 외 정치·역사·지정학·금리·에너지·방산 등 다양한 질문에 대한 QA.

## 3단계: 구독 베타와 미국 기업 매각을 고려한 운영 (전체 약 2~3개월 이상)
- 데이터 신선도, 백엔드 관측 가능성, 자동 업데이트·실패 감지, 모델·검색 비용 제한, 통합 QA.
- 계정, 이용권, 사용자 의사결정 메모 보안, 데이터 라이선스와 제공 범위 문서화.
- 정확성·출처·응답시간과 사용자 반복 이용을 증명할 수 있는 지표 마련.
- 실제 제품 매각 준비에는 이보다 추가적인 사업 개발·계약·법률 검토가 필요하다.

## 필수 통과 조건
- 적어도 40개의 자유 질문(기업·법안·의원·역사·시장·모호하거나 황당한 질문)에서 직접 답하거나, 정확히 무엇을 확인하지 못했는지와 관련 자료를 보여줄 것.
- 구체적 가격·법안·의원·기업 수치마다 자료 기준일과 원문 URL 제시. 없음은 미확인.
- 실시간 뉴스/가격 조회 실패 시 당일 원인과 가격을 지어내지 않을 것.
- 비로그인 상태에서 미국 페이지의 HTML·JS·데이터·API 접근 차단을 실제로 확인할 것.
- 모바일/PC에서 질문·근거·사진·지도 이동·초기화가 모두 작동할 것.

## 제품 철학
데이터는 증거, AI는 참모, 지도는 추적 도구, 결정권은 운영자에게 있다. 이것이 단순 대시보드가 아닌 MONEY TRACKER 관제실의 경쟁력이다.
