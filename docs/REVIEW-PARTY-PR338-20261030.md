# PR #338 정당별 돈 추적 — 병합 전 개인정보·자료권리·정확성 검토 (2026-10-30)

> 범위: `cursor/party-money-map` @ `34400e142451c2680e5c4801cdbe0a6e4f02c4e5`. GPT 제2 검토 문서. 데이터·화면·수집기 수정 없음. **PR #338은 작성자가 명시한 대로 사장님 확인 전 병합 금지.**

## P1 — 개인사업자 익명화가 공개 JSON에서 보장되지 않음

**재현 경로**
- `scripts/build_party_money.py`: `payee_type == '개인사업자'`이면 `location` 텍스트만 첫 3개 토큰으로 줄이고, `payee`는 `MASK` 목록과 일치하는 일부 행에만 치환함. 선택 입력 `indiv_biz_like_names.csv`가 없으면 `MASK=set()`으로 조용히 진행함.
- 동일 코드가 개인사업자에도 `round(lat, 5), round(lon, 5)`를 저장함. 시군구까지만 보여 준다는 설명과 달리 공개 JSON에는 5자리 좌표가 남음. 근사 좌표일 수 있으므로 **실제 주소를 특정했다고 단정하지는 않음**.
- `assets/mt-party-layer.js`: 지도 팝업은 `p[2]`(상호명), `p[4]`(위치 텍스트), `p[0:2]`(좌표)를 그대로 사용함. `p[7]` 근사치 안내는 공개 데이터 자체를 익명화하지 않음.
- PR 브랜치 `data/party/pts-5.json`, `pts-6.json`에서 `개인사업자` 유형의 상호명과 5자리 좌표가 실제 포함된 것을 확인함. 여기에는 원문 상호명/좌표를 재게시하지 않음.

**필수 조치 (실장 데이터 담당 + 클로드 UI 담당)**
1. 공개 생성물에서는 **모든 개인사업자**의 개별 상호명·개별 점 좌표를 제거하고 시군구 단위 집계(건수/합계)만 노출하거나, 해당 유형의 지도 점 자체를 제외할 것. 마스킹 CSV의 존재 여부에 안전성이 좌우되어서는 안 됨.
2. 지도에 보이는 정보뿐 아니라 `data/party/pts-*.json` **원본 산출물**도 같은 기준으로 검사할 것. 프런트엔드에서 숨기기만 해서는 부족함.
3. 익명화 정책이 충족되지 않으면 빌드/배포를 실패 처리(fail closed)하고, 개인사업자·개인·법인 유형별 샘플 회귀 테스트를 추가할 것.
4. 공개 전 기존 정적 파일/캐시에도 과거 버전이 남지 않는지 확인할 것.

## P1 — 매각·상업 서비스와 자료 이용 조건 충돌 가능성

- PR의 `assets/mt-party-layer.js`는 중앙선관위 국고보조금 자료를 **'공공누리 출처표시-상업적 이용금지-변경금지'**라고 직접 표기함. 이 표기가 정확하다면 상업 서비스/매각용 상품에 그대로 포함하는 것은 별도 권리 검토가 필요함. 여기서 법적 위반을 확정하는 것은 아님.
- 오마이뉴스·경향신문·뉴스타파 공동 가공 자료는 중앙선관위 공식 원문과 별개일 수 있으므로 재배포·2차 가공·상업 이용 권한을 별도로 확인할 것. `docs/AI-ROLES.md`의 '출처는 공식 원문 링크만' 원칙과 현재 출처 표기가 맞지 않음.
- **권리 확인 전** 문제 자료를 공개 배포 경로에서 제외하거나, 상업 이용·가공·재배포가 허용된 공식 원자료만으로 재구축할 것. 출처별 공식 URL, 이용 허락 근거, 버전, 원문 대조 기록을 남길 것.

## P2 — 사실 검증·실패 상태 표현

- `data/party/index.json`은 `status='팩트체크 확인(2026-10-30), 개혁신당 보조금만 미확인'`이라고 표시함. 그러나 화면에는 개별 집계의 **직접 확인 가능한 공식 원문 URL**이 없고, OCR 오류 가능성을 인정함. 전 항목 검증 완료로 오해할 여지가 있음.
- `assets/mt-party-layer.js`의 index 로드 `fetch(...).then(r => r.json()).then(...)`에는 HTTP 상태 검사·`catch`·재시도 UI가 없음. 404/503/파싱 실패 시 패널은 열리지만 선택지가 비어 원인을 알기 어려움.
- 공식 원문 링크/검증 범위/기준일을 항목별로 표시하고, 미확인 항목은 미확인으로 남길 것. 네트워크·HTTP 오류·잘못된 JSON을 '자료 없음'과 구별해 재시도 버튼을 제공할 것.
