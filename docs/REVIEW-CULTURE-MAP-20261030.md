## 검증된 코드상 문제

## 재현·회귀 테스트 (실행 전 체크리스트)

1. 정상 HTTP 200 + 유효 JSON: 축제·국비 흐름·출연료·영진위 점과 출처 링크가 나타나며 2024/2026 전환과 레이어 토글이 작동한다.
2. HTTP 404와 500: **자료 0건**이 아닌 **불러오기 실패**가 보이고 재시도 가능하며 연도 변경 시 JS 예외가 없다.
3. 네트워크 오프라인/타임아웃: 실패 상태가 보이고 연결 복구 후 재시도 가능하다.
4. HTTP 200 + 잘못된 JSON: 파싱 오류를 사용자에게 표시하고 원자료가 없는 것으로 오인시키지 않는다.
5. HTTP 200 + 스키마 누락(`fest`/`fee`/`film`)과 유효한 빈 배열: 깨진 자료와 정상 0건을 구분한다.
6. 동일 영화 레코드로 10회 새로고침: 좌표가 모두 같고 팝업의 공식 출처·금액·지역명이 변하지 않는다.
7. 375px 가로 및 390px 가로 높이 등 휴대폰 가로 화면: 실패 경고·재시도·처음으로·레이어 선택이 가려지지 않는다.
8. 화면·메타·팝업에서 검증 상태 문구가 일치하고, 계획예산과 집행액, 지원결정액과 실제 지급액을 혼동하지 않는다.
9. CI 통과 외에 실제 배포 URL에서 JSON 요청 상태와 UI 오류 표시를 확인한다.
